Aufgabe III.1

Untersuchen Sie die folgenden Iteratoren auf Fixpunkte und Zyklen:

  • $f(z)=3i\cdot z$
  • $f(z)=\left( \frac{1}{2}+\frac{1}{2}i\right) \cdot z$
  • $f(z)=i\cdot z+5i$
  • Fixpunkte erfüllen $f(z) = z$. Lösen Sie diese Gleichung.
  • Was passiert bei $|a| < 1$, $|a| = 1$, $|a| > 1$?
  • Für $f(z) = az + b$: Der Fixpunkt ist $z = \frac{b}{1-a}$ (falls $a \neq 1$).

Analyse von $f(z) = 3i \cdot z$:

Schritt 1: Fixpunkte \[f(z) = z \Rightarrow 3iz = z \Rightarrow z(3i - 1) = 0 \Rightarrow z = 0\]

Schritt 2: Dynamik

  • $|3i| = 3 > 1$ → expandierende Abbildung
  • $\arg(3i) = 90°$ → Drehung um $90°$ pro Iteration
  • Kombination: Drehung um $90°$ mit Streckung um Faktor 3

Verhalten: Alle Startwerte ausser $z = 0$ divergieren spiralförmig. Keine Zyklen möglich.

Analyse von $f(z) = \left(\frac{1}{2} + \frac{1}{2}i\right) \cdot z$:

Schritt 1: Fixpunkte Analog: nur $z = 0$

Schritt 2: Dynamik

  • $\left|\frac{1}{2} + \frac{1}{2}i\right| = \frac{1}{2}\sqrt{1+1} = \frac{\sqrt{2}}{2} < 1$
  • $\arg\left(\frac{1}{2} + \frac{1}{2}i\right) = 45°$

Verhalten: Alle Startwerte konvergieren spiralförmig gegen 0. Keine Zyklen.

Analyse von $f(z) = i \cdot z + 5i$:

Schritt 1: Fixpunkte \[iz + 5i = z \Rightarrow 5i = z - iz = z(1-i) \Rightarrow z = \frac{5i}{1-i}\]

Berechnung: \[z = \frac{5i}{1-i} \cdot \frac{1+i}{1+i} = \frac{5i(1+i)}{1+1} = \frac{5i + 5i^2}{2} = \frac{5i - 5}{2} = -2.5 + 2.5i\]

Schritt 2: Dynamik

  • $|i| = 1$ → weder Expansion noch Kontraktion
  • $\arg(i) = 90°$ → Drehung um $90°$

Verhalten:

  • Der Fixpunkt $z = -2.5 + 2.5i$ bleibt fest
  • Alle anderen Punkte rotieren um den Fixpunkt
  • Nach 4 Iterationen: $i^4 = 1$ → Zyklen der Länge 4

Jeder Punkt ausser dem Fixpunkt liegt auf einem Zyklus der Länge 4.
