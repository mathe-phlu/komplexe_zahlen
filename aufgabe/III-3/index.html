Aufgabe III.3

Bestimmen Sie den Einzugs-, Divergenzbereich und die Julia-Menge für $f_0$ mit $f_0(z)=z^2$.

  • Untersuchen Sie das Verhalten von $|z_n| = |z_0|^{2^n}$ für verschiedene $|z_0|$.
  • Was passiert für $|z_0| < 1$, $|z_0| = 1$, $|z_0| > 1$?
  • Der Einzugsbereich enthält alle Punkte, deren Orbit gegen 0 konvergiert.
  • Die Julia-Menge ist die Grenze zwischen Einzugs- und Divergenzbereich.

Analyse der Iteration $f_0(z) = z^2$:

Schritt 1: Verhalten der Beträge

Für $z_0 \in \mathbb{C}$ mit $z_{n+1} = z_n^2$ gilt: \[|z_n| = |z_0|^{2^n}\]

Schritt 2: Fallunterscheidung

  • Fall 1: $|z_0| < 1$ \[|z_n| = |z_0|^{2^n} \to 0 \text{ für } n \to \infty\]
  • Fall 2: $|z_0| = 1$ \[|z_n| = 1^{2^n} = 1 \text{ für alle } n\]
  • Fall 3: $|z_0| > 1$ \[|z_n| = |z_0|^{2^n} \to \infty \text{ für } n \to \infty\]

Schritt 3: Klassifikation der Bereiche

Einzugsbereich von 0:

\[E_0 = \{z \in \mathbb{C} : |z| < 1\}\] Das ist das Innere des Einheitskreises.

Divergenzbereich:

\[D_0 = \{z \in \mathbb{C} : |z| > 1\}\] Das ist das Äussere des Einheitskreises.

Julia-Menge:

\[J_{f_0} = \{z \in \mathbb{C} : |z| = 1\}\] Die Julia-Menge ist der Einheitskreis selbst.
