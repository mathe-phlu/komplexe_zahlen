Aufgabe I.10

Erzeugen Sie ein GeoGebra-Applet, mit dem Sie die Wirkung von $z^2$ erkunden können.

Hinweis: Wählen Sie einen beliebigen Punkt $P$ und überlegen Sie, mit welchen GeoGebra‑Funktionen Sie in Abhängigkeit von den Eigenschaften von $P$ eine Drehstreckung erzeugen können.
  • Definieren Sie einen beweglichen Punkt $z$ in der komplexen Ebene.
  • Messen Sie Betrag $r = |z|$ und Argument $\alpha = \arg(z)$.
  • Für $z^2$ gilt: Betrag wird quadriert, Argument wird verdoppelt.
  • Konstruieren Sie $z^2$ mit $|z^2| = r^2$ und $\arg(z^2) = 2\alpha$.
  • Nutzen Sie die Spur-Funktion, um die Bewegung zu verfolgen.
  • Experimentieren Sie mit verschiedenen Startpositionen von $z$.

Schritt 1: Blenden Sie das Koordinatensystem ein und zeichnen Sie einen beliebigen Ortsvektor $z$.

Schritt 2: Messen Sie den Betrag von $z$: \[r = \text{Länge}[z]\]

Schritt 3: Messen Sie das Argument $\alpha$. Dafür definieren Sie zusätzlich einen Punkt auf der x-Achse: \[C = (4, 0)\] Messen Sie dann den Winkel zwischen $C$, Ursprung und $z$.

Schritt 4: Konstruieren Sie $z^2$ durch:

  • Zeichnen Sie einen Kreis um den Ursprung mit Radius $r^2$
  • Definieren Sie einen Strahl vom Ursprung mit Winkel $\beta = 2\alpha$ zur x-Achse
  • Der Schnittpunkt von Kreis und Strahl ist $z^2$

Schritt 5: Bewegen Sie den Punkt $z$ und beobachten Sie:

  • Punkte auf dem Einheitskreis bleiben auf dem Einheitskreis
  • Punkte innerhalb werden näher zum Ursprung gezogen
  • Punkte ausserhalb entfernen sich vom Ursprung
  • Die Drehung ist immer doppelt so gross wie bei $z$

Speichern:

Speichern Sie die Datei als «Zquadrat.ggb».
