Aufgabe I.11

Passen Sie das Applet aus Aufgabe I.10 so an, dass nur Punkte auf dem Einheitskreis betrachtet werden.

  • Zeichnen Sie einen Kreis mit Radius 1 um den Ursprung.
  • Binden Sie den Punkt $z$ auf die Kreislinie («Umdefinieren» in GeoGebra).
  • Beobachten Sie, dass $z^2$ ebenfalls auf dem Einheitskreis liegt.
  • Das Argument wird verdoppelt, der Betrag bleibt 1.
  • Untersuchen Sie spezielle Positionen wie $z = i$ oder $z = -1$.

Schritt 1: Öffnen Sie die Datei «Zquadrat.ggb» aus Aufgabe I.10.

Schritt 2: Zeichnen Sie einen Kreis mit $r = 1$ um den Ursprung.

Schritt 3: Binden Sie den Punkt $z$ auf die Kreislinie:

  • Rechtsklick auf $z$ → «Umdefinieren»
  • Wählen Sie «Punkt auf Objekt» und klicken Sie auf den Einheitskreis

Beobachtungen:

  • Für $|z| = 1$ gilt stets $|z^2| = |z|^2 = 1^2 = 1$
  • Das bedeutet: $z^2$ liegt ebenfalls auf dem Einheitskreis
  • Das Argument wird verdoppelt: $\arg(z^2) = 2 \cdot \arg(z)$
  • Nach einer vollen Umdrehung von $z$ macht $z^2$ zwei Umdrehungen
