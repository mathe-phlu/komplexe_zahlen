Was bewirkt die Funktion $w=f(z)=iz-2i+2$ in geometrischer Hinsicht?

  • Schreiben Sie die Funktion in der Form $f(z) = az + b$.
  • Berechnen Sie $|a|$ und $\arg(a)$ - was bedeuten diese Werte?
  • Lösen Sie $f(z) = z$ für den Fixpunkt.

Vorgehen zur Analyse der Funktion:

Schritt 1: Identifikation der Parameter \[f(z) = iz - 2i + 2 = iz + (2-2i)\] Also: $a = i$ und $b = 2-2i$

Schritt 2: Analyse des Faktors $a = i$

Betrag berechnen: \[|a| = |i| = \sqrt{0^2 + 1^2} = 1\] $\Rightarrow$ Keine Streckung (Faktor 1)

Argument berechnen: Da $i = 0 + 1i$ auf der positiven imaginären Achse liegt: \[\arg(i) = 90°\] $\Rightarrow$ Drehung um $90°$ gegen Uhrzeigersinn

Schritt 3: Bestimmung des Drehzentrums Für eine Funktion $f(z) = az + b$ mit $a \neq 1$ ist das Drehzentrum (der Fixpunkt): \[Z = \frac{b}{1-a}\]

Mit unseren Werten $a = i$ und $b = 2-2i$: \[Z = \frac{2-2i}{1-i} = \frac{2(1-i)}{1-i} = 2\]

Das Drehzentrum liegt also bei $Z = 2$ (dem Punkt $(2|0)$ in der Gauss'schen Zahlenebene).

Ergebnis:

Die Funktion bewirkt eine reine Drehung um $90°$ gegen den Uhrzeigersinn mit Zentrum $Z = (2|0)$.

Geben Sie eine Funktionsgleichung für eine Drehung um $60^\circ$ im Uhrzeigersinn mit Drehzentrum $(0|2)$.

  • Drehung um $-60°$: $a = \text{cis}(-60°)$.
  • Drehzentrum $Z = 2i$: Nutzen Sie $b = Z(1-a)$.
  • Setzen Sie alles zur Funktionsgleichung zusammen.

Vorgehen:

Schritt 1: Bestimmung von $a$ Drehung um $60°$ im Uhrzeigersinn $\Rightarrow$ Argument $= -60°$ \[a = \text{cis}(-60°) = \cos(-60°) + i\sin(-60°) = \frac{1}{2} - i\frac{\sqrt{3}}{2} = \frac{1-\sqrt{3}i}{2}\]

Schritt 2: Bestimmung von $b$ Aus $Z = \frac{b}{1-a}$ mit $Z = 2i$ folgt: \begin{align*} b &= Z(1-a) = 2i\left(1 - \frac{1-\sqrt{3}i}{2}\right) = 2i \cdot \frac{1+\sqrt{3}i}{2}\\ &= i(1+\sqrt{3}i) = i - \sqrt{3} = -\sqrt{3} + i \end{align*}

Funktionsgleichung: \[f(z) = \frac{1-\sqrt{3}i}{2} \cdot z + (-\sqrt{3}+i)\]

Welche Spezialfälle führen bei der ganzen linearen Funktion …

  1. … auf eine Drehung?
  2. … auf eine zentrische Streckung?

  • Untersuchen Sie die Bedingungen an $a$ in $f(z) = az + b$.
  • Wann ist nur Drehung ohne Streckung? Wann nur Streckung ohne Drehung?
  • Was muss für $b$ gelten, damit das Zentrum im Ursprung liegt?

(a) Drehung
Eine reine Drehung liegt vor, wenn:

  • $|a| = 1$ (keine Streckung)
  • $a \neq 1$ (sonst nur Verschiebung)

(b) Zentrische Streckung
Eine zentrische Streckung liegt vor, wenn:

  • $a \in \mathbb{R}$ mit $a \neq 1$ (reeller Faktor)
  • Der Streckfaktor ist dann $k = a$

Spezialfall - Zentrum im Ursprung:

Zusätzlich $b = 0$:

  • Drehung um Ursprung: $f(z) = az$ mit $|a| = 1$
  • Streckung am Ursprung: $f(z) = az$ mit $a \in \mathbb{R} \setminus \{1\}$
