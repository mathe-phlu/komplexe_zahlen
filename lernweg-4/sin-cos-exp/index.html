Werten Sie die Exponentialreihe $\exp(z)$ an der Stelle $z=iy$ aus (also für eine imaginäre Zahl).
  • Setzen Sie $z = iy$ in die Exponentialreihe ein.
  • Berechnen Sie die Potenzen von $i$ systematisch.
  • Sortieren Sie nach Real- und Imaginärteil.

Systematisches Vorgehen:

Schritt 1: Einsetzen in die Exponentialreihe \begin{align*} \exp(iy) &= \sum_{n=0}^{\infty} \frac{(iy)^n}{n!}\\ &= 1 + iy + \frac{(iy)^2}{2!} + \frac{(iy)^3}{3!} + \frac{(iy)^4}{4!} + \frac{(iy)^5}{5!} + ... \end{align*}

Schritt 2: Potenzen von $i$ berechnen

$$i^0 = 1,\; i^1 = i,\; i^2 = -1,\; i^3 = -i,\; i^4 = 1, \; i^5 = i, ... $$

Schritt 3: Einsetzen der Potenzen \begin{align*} \exp(iy) &= 1 + iy - \frac{y^2}{2!} - i\frac{y^3}{3!} + \frac{y^4}{4!} + i\frac{y^5}{5!} - \frac{y^6}{6!} - i\frac{y^7}{7!} + ... \end{align*}

Schritt 4: Nach Real- und Imaginärteil sortieren \begin{align*} \exp(iy) &= \underbrace{\left(1 - \frac{y^2}{2!} + \frac{y^4}{4!} - \frac{y^6}{6!} + ...\right)}_{\text{Realteil}}\\ &\quad + i\underbrace{\left(y - \frac{y^3}{3!} + \frac{y^5}{5!} - \frac{y^7}{7!} + ...\right)}_{\text{Imaginärteil}} \end{align*}

Schritt 5: Identifikation der Reihen

  • Realteil: Das ist die Taylorreihe von $\cos(y)$
  • Imaginärteil: Das ist die Taylorreihe von $\sin(y)$

Ergebnis - Die Euler-Formel:

\[\boxed{e^{iy} = \cos(y) + i\sin(y) = \text{cis}(y)}\]
